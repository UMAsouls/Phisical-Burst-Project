# Physical-Burst-Project
Unityで作成したSRPG風の戦闘ゲームです。
攻撃の際にお互いに技を出し、その相性で結果が変わることが特徴です。有利な状況を見極めて、上手く敵モンスターの全滅を目指すのが目的です。

## 制作期間
2ヶ月

## 制作人数
1人

## 操作方法
| キー操作 | アクション |
| ---- | ---- |
| WASD | カーソル移動 |
| Enter | 決定 |
| Backspace | キャンセル |

## 使用した技術・設計の工夫
- 言語：C#
- エンジン：Unity

制作中はゲーム内コマンド（以下コマンド）を多く作っても制作が容易になるよう、保守性の高い設計を目指しました。

まず、コマンド自体の処理に幅を持たせるため、**Commandパターン**をコマンドの設計に用いました。
これにより、既存コードを修正せずにコマンドを追加することが可能になっています。

さらに回復や遠距離攻撃用コマンドのインスタンスを実際に作成する際には**Factoryパターン**を用いました。
キャラクター側が内部実装を知らなくても攻撃座標などを保存した命令インスタンスを作成できるようになっています。

これ以外にも様々な部分でデザインパターンを用いた設計を行っています。

また、ゲーム進行のロジックをシンプルにするため、入力待機にはUniTaskによる非同期処理を用いています。
これによりゲーム中の状態遷移を1つのプログラムの流れとして記述することができました。
